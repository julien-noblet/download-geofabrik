# FIT VUT Brno Extracts Catalog

[← Back to README](../../README.md)

- **Service Key**: `osm.fit.vutbr.cz`
- **Description**: Czech Republic national extracts by date
- **Example**: `download-geofabrik --service osm.fit.vutbr.cz download 2026-09-06`

> [!NOTE]
> This service offers extracts for Czech Republic indexed by date (`YYYY-MM-DD`).
> Specify any date (e.g. `2026-09-06`), `latest` for the most recent extract, or `czech_republic` for the `.poly` file.

## Available Elements

| SHORT NAME     | IS IN | LONG NAME               | FORMATS |
|----------------|-------|-------------------------|---------|
| czech_republic |       | Czech Republic          | p       |
| latest         |       | Czech Republic (latest) | P       |
