# OpenStreetMap Italia Extracts Catalog

[← Back to README](../../README.md)

- **Service Key**: `osmit-estratti`
- **Description**: Italy national, regional, and provincial extracts
- **Example**: `download-geofabrik --service osmit-estratti download toscana`
